A single original one-liner joke, written by a small TypeScript program
(`main.ts`, Node 22, stdlib only) to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR`. One line, one setup, one surprise payoff — no words wasted.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-liner-out node main.ts
cat /tmp/one-liner-out/entry.txt
```
